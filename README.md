# Emotion Detection from Text

Classifies a sentence into one of 6 emotions: sadness, joy, love, anger, fear, surprise.

## Details
- Dataset: https://huggingface.co/datasets/dair-ai/emotion
- Pretrained model: https://huggingface.co/distilbert-base-uncased
- Fine-tuned model: https://huggingface.co/Sammi111/emotion-distilbert
